# CantonCareCompass　廣州養老政策速查

廣州養老政策速查｜規則引擎自動匹配，非AI估算，缺資料會直接話你知

## 呢係咩

輸入長者嘅個案情況（年齡、戶籍、經濟狀況、失能等級、居住狀況等），自動比對可能適用嘅廣州養老服務政策，供社工做**初步篩查參考**。個案描述支援簡體／繁體輸入，系統會自動識別。

全部判斷都係**明文規則**（if/else邏輯），冇call任何AI模型。缺乜資料，會直接列為「仍需確認」，唔會自行假設或者估算。
使用網址：https://loegunn.github.io/cantoncarecompass

## 主要功能

- **個案匹配**：填寫個案資料（或者貼上一段文字描述，工具會自動識別關鍵字回填，簡體繁體都得），一鍵匹配政策
- **政策庫**：瀏覽已收錄嘅全部政策條目，睇適用條件、資助標準、申請材料同渠道
- **養老機構名錄**：搜尋天河區養老機構嘅地址、電話、性質、床位數

## 資料來源

整理自：
- 某街頤康中心養老政策宣講材料（2026年7月）
- 《廣州市公辦養老機構入住評估輪候管理辦法》（穗民規字〔2026〕2號）
- 天河區養老機構基本信息表
- 某街頤康中心公開宣傳資料
- 《廣州市計劃生育獎勵和特別扶助辦法》（穗府辦規〔2022〕8號）

各政策條目內均標明具體來源、發布日期同版本狀態；如發現唔同來源資料有出入，會喺對應政策詳情內特別提示。

## 使用限制（請務必留意）

- 呢個係**純前端工具**，所有運算喺瀏覽器本機完成，唔會上傳任何輸入資料
- **唔會自動更新**——政策內容係某個時間點嘅snapshot，隨政策調整可能過時
- **只供初步篩查參考，唔可以取代正式審批**——具體資格務必以官方最新政策同經辦部門確認為準
- 機構聯絡資料如有變動，請以機構官方公佈為準

## 創作理念

呢個工具純粹係我自己喺工作之餘摸索出嚟嘅嘢，**我本身冇IT背景**，全部都係靠自己一路試一路學。

出發點好簡單——見到自己同同事平時成日要喺一大堆政策文件入面搵邊條啱用邊個個案，好費時間，就諗住AI可唔可以幫手，令社工日常做嘢方便啲。而家仍然喺度摸索緊，呢個工具都只係其中一個小小嘗試，肯定仲有好多做得未夠好嘅地方。

如果你都係社工、都喺度諗緊AI可以點幫到手，希望大家可以互相撐住——一齊摸索，一齊分享，遇到做得唔啱嘅地方，直接講出嚟，唔使客氣。

最緊要嘅係，用AI學嘢、用AI做嘢嘅過程入面，唔好失去自己嘅專業判斷同初心。工具始終係工具，行埋出去做個案、陪伴服務對象嗰份心，先係我哋做呢行嘅根本。

今宵多珍重。
