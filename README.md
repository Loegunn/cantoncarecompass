# CantonCareCompass　廣州養老政策速查

廣州養老政策速查｜規則引擎自動匹配，非AI估算，缺資料會直接話你知

🔗 **使用網址**：https://loegunn.github.io/cantoncarecompass

## 呢係咩

輸入長者嘅個案情況（年齡、性別、戶籍、經濟狀況、失能等級、居住狀況等），自動比對可能適用嘅廣州養老服務政策，供社工做**初步篩查參考**。

全部判斷都係**明文規則**（if/else邏輯），冇call任何AI模型。缺乜資料，會直接列為「仍需確認」，唔會自行假設或者估算。

## 主要功能

- **個案匹配**：填寫個案資料，或者貼上一段文字描述，工具會自動識別關鍵字回填，一鍵匹配政策
- **政策庫**：瀏覽已收錄嘅全部政策條目，睇適用條件、資助標準、申請材料同渠道
- **養老機構名錄**：搜尋天河區養老機構嘅地址、電話、性質、床位數
- **繁簡切換**：右上角有個「簡／繁」掣，撳一下成版轉換，系統會記住你嘅選擇
- **簡繁輸入都得**：個案描述用簡體定繁體打都識別到
